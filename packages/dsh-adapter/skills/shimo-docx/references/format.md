# 版式参数与来源

参数全部在 `assets/style.json`。来源：redhead-docx 的通用红头草稿模板（generic-redhead-draft-v4）与其生成脚本；它参照 GB/T 9704-2012《党政机关公文格式》做排版近似，不等于任何单位的正式模板，也不保证符合全部公文规范。

## 页面与文字

| 项目 | 值 |
|---|---|
| 纸张 | A4（210 × 297 mm） |
| 页边距 | 上 37 / 下 35 / 左 28 / 右 26 mm；版心约 156 × 225 mm |
| 页眉 / 页脚距边 | 15 / 17 mm |
| 标题 | 22pt（二号）小标宋，黑色，居中，行距 32pt，段后 29pt |
| 正文 | 16pt（三号）仿宋_GB2312，固定行距 29pt，首行缩进 32pt（2 字） |
| 一级标题 | 16pt 黑体，首行缩进 2 字，与下段同页 |
| 二级标题 | 16pt 楷体 |
| 三、四级标题 | 16pt 仿宋 |
| 页码 | 14pt 宋体 `— n —`；首页与奇数页右侧、偶数页左侧，各缩进 14pt；PAGE 域 |

## 红头要素（redhead）

| 项目 | 值 |
|---|---|
| 份号 / 密级 / 紧急程度 | 版心左上，16pt 黑体，逐行 |
| 发文机关标志 | 42pt 小标宋 #FF0000，居中，行距 46pt；段前约 98pt（每多一行份号/密级减 29pt），按字数压缩字宽（最低 20%） |
| 发文字号 | 16pt 仿宋，居中；有签发人时左空 1 字写字号、右对齐"签发人："+ 楷体姓名 |
| 红线 | 发文字号段落下框线，红色，1.5pt（12/8pt），距文字 11pt |
| 标题 | 红线下空两行 |
| 主送 | 顶格，末尾全角冒号 |
| 落款 | 署名、日期右对齐，按两者字宽计算右缩进，使日期右空约 4 字、署名居日期上方 |
| 待盖章 | `seal_mode: reserved` 时在落款上方写灰色【待盖章位置】，不放印章 |
| 附件说明 | 正文下空一行，"附件："悬挂缩进，多个附件编号 1. 2. |
| 附件页 | 另起页；"附件n"16pt 黑体顶格；附件标题 22pt 小标宋居中 |
| 版记 | 末页底部浮动表格，宽 156mm；抄送行与印发行各 25pt 高，14pt 仿宋；首末黑线 1pt、中间 0.75pt |
| 信函格式 | 首页页眉写红色发文机关标志 30pt 加上粗下细双红线，页脚下细上粗双红线；首页无页码；上边距 70mm |
| 草稿标记 | 每页页眉右侧"草稿 · 待核定"，10pt 灰色 |

## 表格（扩展：原 skill 无）

原 redhead-docx 不支持表格。本 skill 新增，参数按公文常见做法定：全框 0.5pt 黑色单线；表头 14pt 黑体居中并在跨页时重复；内容 14pt 仿宋，首列左对齐其余居中，固定行距 22pt；表宽等于版心宽；表题在表上方居中 16pt 黑体；表后空半行，可写表注。

## 已知近似

红头位置、红线距离、落款缩进是按字宽估算的近似值，没有按印刷公差测量；不同字体、Word/WPS 版本会有差异。主送过长可能把正文挤出首页，需要人工把主送移到版记。版记固定在末页底部，正文贴近页末时可能重叠。
